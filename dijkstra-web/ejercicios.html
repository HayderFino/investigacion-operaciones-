Pregunta 3. Implementar el algoritmo Ford-Fulkerson

3.1 ¿Qué es Ford-Fulkerson?

El algoritmo Ford-Fulkerson es un método iterativo para encontrar el flujo máximo en una red dirigida y capacitada. Su funcionamiento consiste en buscar sucesivamente caminos orientados desde el origen hasta el destino con capacidad residual disponible, llamados caminos aumentantes.

El algoritmo sigue estos pasos:

  1. Inicializar todos los flujos en cero: .
  2. Buscar un camino aumentante disponible desde hasta en la red residual.
  3. Identificar la capacidad residual de cada arco del camino.
  4. Encontrar el cuello de botella (capacidad residual mínima) del camino.
  5. Aumentar el flujo total en la cantidad del cuello de botella.
  6. Actualizar las capacidades residuales en la red.
  7. Repetir el procedimiento hasta que no existan más caminos aumentantes disponibles.

3.2 Conceptos fundamentales

  • Capacidad residual: Es la capacidad restante disponible en una conexión:
  • Cuello de botella: Es la menor capacidad residual encontrada dentro del camino :
  • Flujo acumulado: Suma de los incrementos en cada iteración:

Python Evidencia Computacional: Algoritmo de Ford-Fulkerson

A continuación se presenta un programa en Python autónomo que reproduce paso a paso las 5 iteraciones y comprueba matemáticamente las 22 toneladas y el corte mínimo de la red logística: 

"""
Taller 5 de Noviembre 2026: Red Logística para el Transporte de Material Recuperado
Algoritmo de Ford-Fulkerson - Comprobación del Flujo Máximo
"""

class MaxFlowNetwork:
    def __init__(self, nodes):
        self.nodes = nodes
        self.capacity = {u: {v: 0 for v in nodes} for u in nodes}
        self.flow = {u: {v: 0 for v in nodes} for u in nodes}

    def add_edge(self, u, v, cap):
        self.capacity[u][v] = cap

    def augment_path(self, path):
        # 1. Hallar cuello de botella
        bottleneck = min(self.capacity[path[i]][path[i+1]] - self.flow[path[i]][path[i+1]]
                         for i in range(len(path) - 1))
        # 2. Incrementar flujo a lo largo de la ruta
        for i in range(len(path) - 1):
            u, v = path[i], path[i+1]
            self.flow[u][v] += bottleneck
        return bottleneck

# Inicialización de la red logística (6 nodos)
nodes = ['S', 'A', 'B', 'C', 'D', 'T']
net = MaxFlowNetwork(nodes)

# 10 arcos dirigidos con sus capacidades
edges = [
    ('S', 'A', 12), ('S', 'B', 10),
    ('A', 'B', 4),  ('A', 'C', 8),  ('A', 'D', 5),
    ('B', 'D', 7),  ('B', 'C', 6),
    ('C', 'D', 3),  ('C', 'T', 10),
    ('D', 'T', 12)
]
for u, v, c in edges:
    net.add_edge(u, v, c)

# Secuencia de caminos aumentantes del taller
paths = [
    ['S', 'A', 'C', 'T'],
    ['S', 'A', 'D', 'T'],
    ['S', 'B', 'C', 'T'],
    ['S', 'B', 'D', 'T'],
    ['S', 'B', 'C', 'D', 'T']
]

print("=== EJECUCIÓN DE FORD-FULKERSON ===")
total_flow = 0
for idx, path in enumerate(paths, 1):
    delta = net.augment_path(path)
    total_flow += delta
    print(f"Iteración {idx}: {' -> '.join(path):<22} | Cuello de botella: {delta} ton | Acumulado: {total_flow} ton")

print(f"\nFlujo Máximo Final comprobado: {total_flow} toneladas/jornada")
print("\n=== CARGA FINAL POR CONEXIÓN ===")
for u, v, c in edges:
    f = net.flow[u][v]
    sat = " [100% SATURADO]" if f == c else ""
    print(f"Arco {u} -> {v}: flujo {f:>2}/{c:>2} ton (residual: {c - f:>2}){sat}")
